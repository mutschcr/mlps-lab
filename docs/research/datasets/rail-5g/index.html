Overview

RAIL-5G was recorded at the SNCF Technicentre in Bischheim, France, where rail equipment, metallic structures and narrow corridors create demanding radio propagation conditions.

The dataset includes wideband 5G channel impulse responses and sub-millimeter ground truth for AI-based indoor localization.

Area811 m²

Bandwidth100 MHz
Recording sets8

Measurement setup

A 5G NR system at 3.95 GHz (band n77) uses 100 MHz SRS reference signals with eight distributed radio units. The user equipment is mounted on a mobile robot.

The environment spans approximately 811 m². Optical ground truth is captured using a 7D Kinematic Metrology iGPS system at 40 Hz.

Data format & contents

  • HDF5 dataset ds includes antenna_mask, CIR, interpolation_diff, reference, timestamp and toa.
  • Each CIR has shape (2, 8, 96): real/imaginary components, eight base stations and 96 delay taps.
  • Eight recordings cover corridor, open-area and full-area trajectories.
  • Recording sizes range from 25,809 to 68,045 snapshots per take.
